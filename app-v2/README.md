# Home_69 — новая версия приложения

Новая версия размещена отдельно в `app-v2/`; существующая версия в корне репозитория не изменяется.

## Состав
- `index.html` — интерфейс приложения.
- `styles.css` — адаптивный тёмный Glassmorphism-дизайн.
- `app.js` — логика показаний, объектов, расчётов, платежей и синхронизации.
- `initial-data.json` — исходный архив показаний, тарифов, услуг, приборов и платежей.

## Возможности
- Неограниченное число квартир и домов.
- Настраиваемый набор приборов для каждого объекта: газ, холодная вода, однотарифное или двухтарифное электричество.
- Автоматический расчёт расхода относительно предыдущих показаний.
- Архив и графики потребления.
- Тарифы по счётчикам и услуги ЖКХ с начислением за человека, квартиру, квадратный метр или фиксированной суммой.
- Фактическая сумма квитанции и фактическая оплата хранятся отдельно от расчётного начисления.
- Разовые и ежегодные платежи с произвольной суммой (например, ТО газового оборудования).
- Серийные номера счётчиков и даты поверки.
- Резервное копирование и импорт JSON.
- Синхронизация через PocketBase.

## Развёртывание на Synology
1. Скопировать **содержимое** папки `app-v2` в отдельную папку веб-сервера, например `/web/home69-v2/`.
2. Открыть `https://адрес-сервера/home69-v2/`.
3. В разделе «Объекты и настройки» указать URL PocketBase (например, `http://адрес-сервера:8093`) и имя коллекции `state`.
4. Если коллекция закрыта правилами доступа, указать email и пароль пользователя PocketBase. Не включать публичную запись для всего интернета.
5. Сохранить подключение. Приложение создаёт запись `main`, если её ещё нет.

## PocketBase
Используется совместимая с предыдущей версией коллекция `state` с полями:
- `data` — JSON, всё состояние приложения версии 2;
- `tariffs` — JSON (служебное поле совместимости);
- `services` — JSON;
- `payments` — JSON;
- `meters` — JSON;
- `updatedAt` — number.

Типы и имена полей должны совпадать с уже существующей коллекцией `state`. Если коллекция была создана с другой схемой, перед подключением проверьте её поля в админке PocketBase.

## Важное о миграции
Исторический JSON импортируется в новую модель при первом запуске. Исходный `initial-data.json` не изменяется. До первого подключения к PocketBase рекомендуется скачать резервную копию из приложения. Старые записи платежей за газ и капитальный ремонт сохраняются отдельными строками в журнале разовых платежей.
